AWS 3-Tier Web Application Architecture

Project Overview

This project demonstrates a highly available and scalable 3-Tier Web Application Architecture using Amazon Web Services (AWS).

AWS Services Used

- Amazon VPC
- Amazon EC2
- Application Load Balancer (ALB)
- Auto Scaling Group
- Amazon RDS (Multi-AZ)
- Amazon Route 53
- Amazon CloudFront
- AWS WAF
- Amazon CloudWatch

Architecture

The application follows a three-tier architecture:

1. Presentation Layer – Handles user requests.
2. Application Layer – Processes application logic using EC2 instances.
3. Database Layer – Stores application data using Amazon RDS.

Key Features

- High availability
- Scalability
- Load balancing
- Database redundancy
- Monitoring and security
